Workout Unit Test Documentation

This document shows a small selection of workout-related unit tests and briefly explains what each test verifies.

1. Mapping request data into a Workout domain object

File: src/test/java/com/zeki/demo/Unit/WorkoutTest.java

@Test
void toDomainUsesProvidedWorkoutCategory() {
    CreateWorkoutRequest request = createWorkoutRequest(WorkoutCategory.STRENGTH, MuscleType.LEGS);

    Workout workout = workoutDtoDomain.toDomain(request, TEST_EMAIL);

    assertEquals(WorkoutCategory.STRENGTH, workout.getCategory());
    assertEquals(MuscleType.LEGS, workout.getMuscleType());
    assertEquals(TEST_EMAIL, workout.getUserEmail());
    assertEquals(4, workout.getSets());
    assertEquals(10, workout.getReps());
}

This test verifies that request data is mapped correctly into the Workout domain object and that the provided category, muscle type, and user ownership are preserved.

4. Blocking unauthorized workout updates

File: src/test/java/com/zeki/demo/Unit/WorkoutServiceTest.java

@Test
void updateWorkoutWhenNotOwnedByUserThrowsUnauthorized() {
    UUID workoutId = UUID.randomUUID();
    Workout existing = validWorkout(workoutId, OWNER_EMAIL);
    UpdateWorkoutRequest request = updateRequest(
            workoutId,
            LocalDate.now().plusDays(1),
            45,
            5,
            12,
            85.0,
            MuscleType.CORE
    );

    when(workoutRepository.getWorkoutById(workoutId)).thenReturn(Optional.of(existing));
    when(workoutRepository.isOwnedByUser(workoutId, OTHER_EMAIL)).thenReturn(false);

    UnauthorizedException ex = assertThrows(
            UnauthorizedException.class,
            () -> workoutService.updateWorkout(workoutId, request, OTHER_EMAIL)
    );

    assertEquals("You cannot update this workout", ex.getMessage());
    verify(workoutRepository, never()).save(any());
}

This test verifies that a user cannot update another user's workout and that the repository save operation is not executed when authorization fails.

5. Persisting workout updates for the owner

File: src/test/java/com/zeki/demo/Unit/WorkoutServiceTest.java

@Test
void updateWorkoutWhenOwnedPersistsUpdatedWorkout() {
    UUID workoutId = UUID.randomUUID();
    Workout existing = validWorkout(workoutId, OWNER_EMAIL);
    UpdateWorkoutRequest request = updateRequest(
            workoutId,
            LocalDate.now().plusDays(2),
            50,
            6,
            6,
            140.0,
            MuscleType.CHEST
    );

    when(workoutRepository.getWorkoutById(workoutId)).thenReturn(Optional.of(existing));
    when(workoutRepository.isOwnedByUser(workoutId, OWNER_EMAIL)).thenReturn(true);
    when(workoutRepository.save(any(Workout.class))).thenAnswer(invocation -> invocation.getArgument(0));

    Workout updated = workoutService.updateWorkout(workoutId, request, OWNER_EMAIL);

    assertEquals(UPDATED_NAME, updated.getWorkoutName());
    assertEquals(WorkoutCategory.CARDIO, updated.getCategory());
    assertEquals(50, updated.getDurationMinutes());
    assertEquals(6, updated.getSets());
    assertEquals(6, updated.getReps());
    verify(workoutRepository).save(any(Workout.class));
}

This test verifies that a workout owner can update the workout successfully and that the changed values are persisted.
